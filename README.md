# Estudio Paraíso — Reservas

App pública de reservas del estudio fotográfico Estudio Paraíso (Centro Histórico, CDMX).

- Página estática (un solo index.html) con el diseño del PDF original.
- Paquetes: Luz natural $400 MXN/hora, Luz artificial $550 MXN/hora, mínimo 2 horas.
- Reserva por Instagram DM a @estudio_paraiso, apartado del 50%.
- Pago por transferencia (Nubank, datos en la página) o tarjeta con Mercado Pago.
